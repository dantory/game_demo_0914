# Ashen Courtyard · 잿빛 안뜰

SpriteShip에서 만든 기사를 직접 조작하는 작은 브라우저 전투 데모.

## 실행

배포 주소: https://dantory.github.io/game_demo_0914/

- WASD: 이동
- 마우스 이동: 조준
- 마우스 왼쪽 클릭: 커서 방향 근접 공격
- I 또는 HUD 가방 버튼: 인벤토리
- 모바일: 화면 아래 방향 버튼과 공격 버튼
- 일시정지 버튼, 승리/패배 후 재시작
- 세 번의 적 웨이브를 막으면 승리

## 에셋과 범위

기사: SpriteShip에서 생성한 남색·금색 기사 1번 시안. 생성된 정면 걷기·공격과 방향 포즈를 활용한다. 전 방향 걷기·공격을 생성한 프로젝트는 아니다. 필드의 32px 바닥·도로 타일셋, 고목, 폐허 제단은 PixelLab에서 생성했으며 맵 워크숍에서 50×34 타일로 조립했다. 게임에서는 1600×1088 월드와 추적 카메라로 사용한다. 무기·갑옷·부적 12종은 OpenAI 이미지 생성으로 제작했고, 적과 UI 구조는 JavaScript/CSS로 제작했다.

몬스터는 웨이브와 보스 여부에 따라 10개 장비 부위의 전리품을 떨어뜨린다. 아이템에는 일반·마법·희귀·전설 등급과 공격력·방어력·최대 체력·치명타·이동 속도 능력치가 있다. 마법 이상 장비에는 부위별 접두·접미 옵션이 붙으며 아이템 레벨에 따라 T5부터 T1까지의 수치 범위를 사용한다. 장착 효과는 전투 계산에 즉시 반영되며 인벤토리와 장비 상태는 브라우저에 저장된다.

SpriteShip 사용: 시안 150 + 방향 준비 400 + 걷기 400 + 공격 400 = 1,350크레딧. 남은 크레딧 150. Godot 내보내기/실행은 이번 웹 데모의 검증 범위에 포함하지 않는다.

## 개발

외부 런타임 의존성 없음. 정적 파일 서버에서 실행한다.

```sh
python3 -m http.server 8080
npm test
```

## 구조

- `src/game.js`: 이동, 충돌, 전투, 렌더링
- `src/items.js`: 아이템 생성, 등급, 장착, 능력치 합산, 저장
- `src/app.js`: 로딩, UI, 키보드/터치 입력
- `assets/manifest.json`: 실제 프레임 좌표 및 재생 설정
- `tests/*.test.js`: 전투, 카메라, 드롭, 인벤토리, 장착, 저장 검증

API 키는 게임에 필요하지 않다. 인증정보는 커밋하지 않는다.
