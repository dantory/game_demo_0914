# 전리품 옵션 시스템

아이템은 `기본 장비 + 기본 속성 + 접두 옵션 + 접미 옵션`으로 구성한다. 전투 계산에는 최종 합산된 `stats`를 사용하지만, 원본 굴림 정보인 `implicit`와 `affixes`도 함께 저장한다. 이를 통해 툴팁의 수치 범위 표시와 이후 옵션 재설정 기능을 구현할 수 있다.

## 생성 규칙

| 등급 | 옵션 수 | 배치 |
| --- | ---: | --- |
| 일반 | 0 | 없음 |
| 마법 | 1 | 접두 또는 접미 |
| 희귀 | 2 | 접두 1 + 접미 1 |
| 전설 | 3 | 접두 2 + 접미 1 또는 접두 1 + 접미 2 |

- 옵션은 장비 부위별 허용 목록에서만 선택한다.
- `group`이 같은 옵션은 한 아이템에 중복되지 않는다.
- 아이템 레벨 1/2/3/5/8에서 각각 T5/T4/T3/T2/T1을 해금한다.
- 각 옵션은 `tier`, `min`, `max`, `value`를 보존한다.
- 이름에는 가장 높은 티어의 접두 하나와 접미 하나를 사용하며, 실제 모든 옵션은 툴팁에 표시한다.

## 저장 호환성

현재 인벤토리 형식은 버전 2다. 기존 버전 1 아이템은 기존 최종 능력치를 유지한 채 불러온다. 새로 획득하는 아이템부터 전체 티어와 굴림 정보를 저장한다.

## 확장 원칙

고유 효과, 옵션 재설정, 제작을 추가할 때는 최종 `stats`를 직접 수정하지 않고 원본 `implicit`와 `affixes`를 변경한 뒤 다시 합산한다. 새 옵션은 부위, 위치, 중복 그룹과 전체 티어 범위를 함께 정의해야 한다.
