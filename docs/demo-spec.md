# 기사 전투 데모

개인 프로젝트. Jira를 사용하지 않는다.

## 목표
SpriteShip에서 생성한 에셋을 실제 브라우저 게임에 연결하고, 생성부터 플레이까지의 작업 흐름을 검증한다. GitHub Pages로 배포한다. Godot 연동 검증은 후속 작업이다.

## 첫 데모
- 탑다운 기사 1명: 이동, 대기, 걷기, 근접 공격
- 작은 맵 1개: 바닥, 벽, 장애물 충돌
- 적 1종: 추적, 피격, 체력, 처치
- 키보드 이동 및 공격, 재시작
- 모바일 방향 조작과 공격 버튼

## 에셋 제작 순서
1. SpriteShip에서 기준 기사 이미지를 생성하고 외형을 검토한다.
2. 확정된 캐릭터를 바탕으로 idle / walk / attack을 생성한다.
3. 같은 스타일로 적과 환경 에셋을 제작한다.
4. 스프라이트시트와 프레임 메타데이터를 가져온다.
5. 게임에 연결하고 방향·피벗·프레임 흔들림·충돌을 확인한다.

## 시각 방향 초안
- 탑다운 픽셀 판타지
- 짙은 남색 갑옷, 금색 장식의 작은 기사
- 초록 슬라임과 폐허 안뜰
- 명확한 실루엣, 일정한 광원과 팔레트

## 검증 기준
- 대기/걷기/공격에서 캐릭터 외형과 발 위치가 유지되는가
- 바닥 타일 경계가 자연스러운가
- 장애물을 통과하지 않고 적을 공격·처치할 수 있는가
- PC와 모바일 화면에서 조작 가능한가
- 배포 주소에서 새로고침 후 정상 실행되는가

## 현재 상태
- 공개 GitHub 저장소 생성 완료
- SpriteShip 로그인 대기: 실제 에셋은 아직 생성하지 않음
- 게임 구현과 GitHub Pages 배포는 아직 완료하지 않음

생성 비용은 실행 전에 확인한다. API 키와 계정 비밀정보는 저장소나 브라우저 게임 코드에 포함하지 않는다.
