# 기사 전투 데모

개인 프로젝트. Jira를 사용하지 않는다.

## 목표
SpriteShip에서 생성한 에셋을 실제 브라우저 게임에 연결하고, 생성부터 플레이까지의 작업 흐름을 검증한다. GitHub Pages로 배포한다. Godot 연동 검증은 후속 작업이다.

## 첫 데모
- 탑다운 기사 1명: 이동, 대기, 걷기, 근접 공격
- 작은 맵 1개: 바닥, 벽, 장애물 충돌
- 적 1종: 추적, 피격, 체력, 처치
- 키보드 이동, 공격, 이동 방향 회피 돌진, 주변 적을 밀쳐내는 일시 강화 함성, 재시작
- 모바일 방향 조작과 공격 버튼

## 에셋 제작 순서
1. SpriteShip에서 기준 기사 이미지를 생성하고 외형을 검토한다.
2. 확정된 캐릭터를 바탕으로 idle / walk / attack을 생성한다.
3. 같은 스타일로 적과 환경 에셋을 제작한다.
4. 스프라이트시트와 프레임 메타데이터를 가져온다.
5. 게임에 연결하고 방향·피벗·프레임 흔들림·충돌을 확인한다.

## 시각 방향 초안
- 탑다운 픽셀 판타지
- 짙은 남색 갑옷, 금색 장식의 작은 기사
- 초록 슬라임과 폐허 안뜰
- 명확한 실루엣, 일정한 광원과 팔레트

## 검증 기준
- 대기/걷기/공격에서 캐릭터 외형과 발 위치가 유지되는가
- 바닥 타일 경계가 자연스러운가
- 장애물을 통과하지 않고 적을 공격·처치할 수 있는가
- PC와 모바일 화면에서 조작 가능한가
- 배포 주소에서 새로고침 후 정상 실행되는가

## 현재 상태
- 공개 GitHub 저장소 생성 완료
- SpriteShip 기사와 걷기·공격 애니메이션 연결 완료
- PixelLab 타일셋·고목·폐허 제단으로 50×34 필드 구성 완료
- AI 생성 무기·갑옷·부적 12종을 드롭·인벤토리·장착 슬롯에 연결 완료
- GitHub Pages 플레이 데모 배포 완료
- 몬스터 드롭, 10개 장비 슬롯, 4개 등급, 인벤토리와 저장 구현 완료
- 엠버 정예의 위치 지정 폭발과 축소 링 예고, 이동·회피 대응 구현 완료
- 바닥 장비에 등급 색상 이름표와 다중 드롭 겹침 방지 적용 완료

## 파밍 설계
- 슬롯: 무기, 방패, 투구, 흉갑, 장갑, 장화, 허리띠, 목걸이, 반지, 부적
- 등급: 일반, 마법, 희귀, 전설
- 능력치: 공격력, 방어력, 최대 체력, 치명타, 이동 속도
- 웨이브가 높을수록 아이템 수치와 상위 등급 확률이 상승한다.
- 마법 이상 장비는 부위별 옵션 풀에서 접두·접미를 굴리며, 아이템 레벨에 따라 T5~T1 티어와 수치 범위가 결정된다.
- 희귀 장비는 접두 1·접미 1, 전설 장비는 접두·접미 2+1 조합을 사용하고 같은 능력치 계열은 한 아이템에 중복되지 않는다.
- 첫 처치와 보스 처치는 장비를 보장한다.
- 장착 상태와 가방은 버전이 지정된 로컬 저장 형식으로 유지한다.

생성 비용은 실행 전에 확인한다. API 키와 계정 비밀정보는 저장소나 브라우저 게임 코드에 포함하지 않는다.
